Servlet

パラメータ名 デフォルト 説明
configPath "app.dicon" S2コンテナの起点として読み込まれる設定ファイルのパスを指定します． このパスはクラスパスに含まれるディレクトリからの相対パス，またはJarファイル内のエントリ名です．
debug false デバッグモードを有効にする場合は "true" を指定します (大文字・小文字は区別されません)． デバッグモードを有効にすると， S2Containerの内容表示 機能を使うことが出来ます．
